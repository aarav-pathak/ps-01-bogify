# PS1: Blogify

A simple blog reader built with React and Vite.

## Details
- **PS Number:** PS1
- **Project Name:** Blogify
- **API Used:** [JSONPlaceholder](https://jsonplaceholder.typicode.com)
  - `https://jsonplaceholder.typicode.com/posts`
  - `https://jsonplaceholder.typicode.com/posts/:id`
  - `https://jsonplaceholder.typicode.com/posts/:id/comments`
  - `https://jsonplaceholder.typicode.com/users/:id`
  - `https://jsonplaceholder.typicode.com/users/:id/posts`

## Routes
- `/` - Home page with welcome text and read posts button
- `/posts` - Post list with search by title
- `/posts/:id` - Full post details with author link and comments
- `/users/:id` - Author profile page with their details and posts
- `*` - 404 page not found with link to home
